# 地理距离与实力档位

两者都是**写作用的近似标尺**，不是考据结论。交付物文首必须写明规则与免责说明。

## 一、地点转移与两地距离

### 换算规则

- 单位用**今制公里**，取整到 50～100 km；`≈` 表示按今地位置推演，不是原书数字。
- 带「」的是原文给的里数或日数；按 **1 里 ≈ 0.5 km** 折算。作品自成体系的里制以原文为准。
- 推演日速：

| 方式 | 日速 |
|---|---|
| 步行 | 30–40 km／日 |
| 快马、换骑 | 100–150 km／日 |
| 舟行（顺流／运河） | 60–100 km／日 |
| 「连日连夜」「每天只睡一两个时辰」 | 取对应方式上限 |

原文写「缓缓」「一路游玩」时下调；写「纵马疾驰」「沿途毫无耽搁」时取上限。

### 真实地名 vs 虚构地名

| 情形 | 做法 |
|---|---|
| 可对应今地（州府、名山、大川、名城） | 折算公里，注明「按今地推演」 |
| 半实半虚（真实州府 + 虚构山庄／山崖／总坛） | 真实段折算，虚构段只给「距某地 X 里」「相去不远」「由 X 向东不一日」 |
| 全架空江湖 | **整表改用行程日数与相对方位**，不写公里 |
| 原文与今地矛盾 | 一律以原文描述优先，并在备注里点明 |

禁止为了表格完整而给虚构地名硬编公里。查不到就写「原书未明写，仅记方位」。

### 路线还原

按原文逐段拆，不要只连起点终点。常见组合：

- 陆路 → 乘车 → 弃车乘船 → 过江 → 舍舟登陆 → 抵城；
- 骑马换骑、昼夜兼程；
- 溯江而上 vs 顺流而下（速度不同）；
- 山道、栈道、关隘、渡口会显著拖慢速度。

每条路线记录：「原文行程描写」「分段距离」「合计」「耗时依据」。

### 地点转移速查表

| 段落 | 转移 | ≈ 距离 | 原文依据／耗时 |
|---|---|---|---|
| 章号 | 起点 → 经某地 → 终点 | 数字 km | 「逐字引文」 |

按书中顺序排列，供判断「能不能赶到」时直接查。表中每条都要能在正文里找到对应段落，不能凭空补站。

## 二、实力档位

### 定档依据的优先级

1. **交手结果**（谁胜谁负、几人联手仍不敌、一招制敌）——最强证据；
2. **作者定评**（「当世第一高手」「内功已臻化境」）；
3. **同级别人物互评**（「剑法之高，自以某人为第一」）；
4. **江湖传言、名号、门派地位**——最弱，须打折。

作品自带排行榜、境界体系、明确分级时**采用原设定**，本档位只作跨作品索引，并在文首说明映射关系。

### 档位数随规模伸缩

| 作品规模 | 建议档数 | 示例 |
|---|---|---|
| 短篇、人物少 | 3 档 | 绝顶／一流／寻常 |
| 标准长篇 | 5 档 | T0 超绝顶／T1 绝顶／T2 一流／T3 二流／T4 寻常 |
| 人物极多、等级森严 | 6 档以上 | 在原书境界体系上细分 |

档位定义写清「定位」而非数值；边界人物注明「可上下浮动一档」。

### 必须记录跃迁曲线

静态档位表对写作帮助有限，关键是**角色在哪一章变了**：

```
角色：第 A–B 章 T3 → 第 C 章得某武功，剑术 T1 但身体 T4 → 第 D 章重伤垂死 T4
    → 第 E 章化解真气，T1 → 末章内功圆满，T1 顶
```

每个跃迁写清四要素：**触发事件｜章节｜新档位｜代价**。代价尤其重要：习得禁术常伴随失明、自宫、内力根基浅、经脉受损；主角可能在剑术上已达顶档却连站都站不稳。

### 特殊处理

- **拆开标注**：「剑术 T1／身体 T4」「毒术 T2／武功 T4」比笼统一个档位有用得多。
- **非战力角色**：医者、毒师、情报贩子、机关师别硬塞档位，另标职能与限制条件。
- **合力**：组合型人物（兄弟、阵法、六人组）按「合力 T2」记，并注明单兵水平。
- **已故／前史人物**：单独标注，避免与当下人物混档。
- **不默认升档**：主角光环、名门出身、持有名器都不能自动升档，以交手结果为准。

### 常见误判

1. 把「某派第一高手」「江南四友中以我武功最低」当成全书排名。
2. 把前史传说人物（「打遍天下无敌手」）与正篇人物放进同一张实时战力表。
3. 忽略状态代价：刚得绝学随即失明、被废、中毒，实际可战力远低于名义档位。
4. 同一角色在不同章段重复用同一个档位，漏掉自宫、传功、易筋、疗伤等跃迁节点。
5. 用「四人联手仍落下风」反推四人各自档位时，忘了联手不等于简单相加。

## 三、与可插入性评估的衔接

地理与实力最终服务于两个判断：

- **赶不赶到**：距离 ÷ 日速 vs 事件间隔（见 `time-and-parallelism.md`）；
- **打不打得过**：把「此刻在场角色档位」写进每个剧情段的 `【】`，写作时一眼可见若主角介入会面对谁。

两段标记都要落在**具体章段**，不要只在文首给一张总表了事。
