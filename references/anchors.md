# 锚点提取与证据分级

## 目标

把「原文里到底写了什么」变成可逐条回溯的清单。产物是一份按章节排序的锚点报告，每行包含：关键词、命中章节、逐字引文、前后文。后续所有时间、地理、实力判断都从这份报告出发，不靠记忆。

## S0 原文体检

按顺序完成，结果写进评估报告开头：

1. **编码**：依次试 `utf-8-sig`、`utf-8`、`gb18030`、`big5`，记录实际命中的编码。UTF-8 BOM 的文件用 `utf-8-sig` 读，否则首字会带 `\ufeff`。
2. **规模**：字符数（含标点空白）。注意「字符数」不等于「字数」，文档里不要混写。
3. **章节结构**：统计章节数与名称，检查编号是否连续。章回体常见两字回目，现代小说章节名较长。
4. **混入内容**：序、跋、作者后记、版本说明、网站整理标注、广告行、目录页。这些常被算进「正文」导致字数与版本判断出错；记录它们的起止位置，检索时排除。
5. **版本**：不要只凭回目判定版本（多数版本回目相同）；以后记落款、异文、用字（如「峯／峰」）等实质证据为准。

### 章节正则库

优先让脚本自动试，取命中数最多且编号递增的一套。自定义正则必须带命名组 `num`（章节号）与 `title`（章节名）：

| 形态 | 正则示例 |
|---|---|
| 网友整理版 `第【3】段：第三章 ername` | `第【(?P<num>\d+)】段：\s*第[一二三四五六七八九十百]+章\s*(?P<title>\S+)` |
| 章回体 `第三回 回目` | `第(?P<num>[一二三四五六七八九十百千零〇两\d]+)回\s*(?P<title>\S+)` |
| 现代分章 `第 12 章 标题` | `第\s*(?P<num>\d+)\s*章\s*(?P<title>\S+)` |
| 卷＋章 `卷三 第七章 标题` | `卷[一二三四五六七八九十\d]+\s*第(?P<num>[一二三四五六七八九十\d]+)章\s*(?P<title>\S+)` |
| 无编号标题 | 传 `--chapter-pattern`，或按空行分段后人工编号 |

中文数字需转成整数（含「廿」「卅」「两」「〇」等变体）。若自动匹配全部失败，先运行 `--list-chapters` 排查，不要默认把全文当成一章继续算时间线。

### 位置索引

建立 `{章节号: 起始字符位置}` 后，用二分或线性扫描把任意命中位置映射到章节号。所有引文输出格式统一为：

```
「<逐字引文>」｜第 N 回｜前 50 字 … 后 50 字
```

这样「某个日期首见第几回」「某句判罚出现在第几回末」都能一次查清，避免把回目写错。

## 五类检索词（通用起点，按作品改写）

**1. 季节与天候**：春、夏、秋、冬、暮春、初夏、盛夏、深秋、隆冬、冰雪、初雪、解冻、花开、落叶、和风、酷暑、天时。
> 武侠小说常以景语暗示时间（「和风熏柳」「一天便热一天」「北方冰雪初销」），这类句子往往比明确日期更可靠。

**2. 日期与节令**：正月、腊月、元夕、清明、中秋、重九、过年、新年、X 月 X 日、X 月十五、X 月之初、是日、当日、次日、翌日、当晚。
> 农历日期保留原字样，不要折算公历；有历史纪年的作品可另建年号对照。

**3. 时长与日数**：行得 X 日、候了 X 日、X 日后、X 日前、X 年来、X 年前、数月、半载、X 年、X 载、连日连夜、每日只睡、兼程、不一日、转眼、迄今、早已。
> 特别标出「X 年后」「X 个月后」——章内跳跃最容易在这里被漏掉。也标出「早在 X 年之前」这类回指旧事的句子，它不等于当前时间。

**4. 行程与里数**：X 里、X 里路、X 百里、千里、里许、相去不远、东行、西去、北上、南下、疾驰、纵马、雇船、舟行、渡江、过岭、舍舟登陆、换骑、驿站、关隘。
> 数字与方向同现的句子是地理推演的唯一硬依据。

**5. 状态、评价与权力转移**：天下第一、当世第一、无敌、第一高手、不是敌手、远非、联手、已臻化境、内力、真气、闭关、面壁、囚、昏迷、自宫、逐出师门、逐出门墙、传位、接任掌门、书信、令旗、气绝、暴毙、身亡、自尽、圆寂、遗命。
> 这类词既支撑实力档位，也标记「谁在哪一刻失去了行动能力」——正是并行窗口的成因。

不同作品要补自己的专有词：门派名、武功名、毒药名、信物名、地名、组织名。词表文件每行一词，用 `--keywords` 传入。

## 证据分级

| 级别 | 定义 | 写法 | 用途 |
|---|---|---|---|
| **A 硬锚点** | 原文明写，可逐字引用 | 「和风熏柳」「行得八九日后，已到了江西境内」「十二月十五」 | 可作时间轴节点、可用来证伪其他结论 |
| **B 可推演** | 由 A 级换算或合理估算 | 按 1 里 ≈ 0.5 km 折算；按日速估算行程；按季节顺序推「第 N 年」 | 必须在文中带 `≈`、`约`、「推演」字样 |
| **C 无依据** | 印象、影视改编、同人二设、凭空补全 | 「林平之逃亡约一个月」而原文只给「行得八九日」 | 一律删除，或明确标「原文未明写」 |

**铁律**：C 级不得升格为 A 级；B 级不得冒充 A 级。已有资料里若把 B 级写成硬锚点，列入错误清单并订正。

## 常见误判（逐条核上下文，不要只看关键词命中）

1. **「三年多来你不出一声」≠「闭关三年多」**：前者是旁人疑心教主被人下哑药，全书可能根本没有「闭关」二字。
2. **「本该逐出师门，只是……反为不美」≠ 已逐出**：道歉信里的假设语气，确认被逐要等后文出示各派书信。
3. **玩笑话 ≠ 正式判罚**：「罚你面壁多加一年」若是师妹打趣，真正判罚在上一回末由师父说出口。
4. **诊断式死期 ≠ 实际存活时长**：名医判「百日之命」后，人物往往还经历数月囚居、两次大会，早超百日。这类数字是悬念，不是硬时钟。
5. **判罚时长 ≠ 实际时长**：判「面壁一年」，后文可能明写「住了半年」就被突发事件打断下山。
6. **首见章节 ≠ 事件发生章节**：一个日期可能先由路人闲谈带出，正事发生在后面几回；分别记录「首见」与「正日」。
7. **推断的路程冒充硬锚点**：原文只给「行得八九日」，资料里写成「约一个月」，属于 C 级。
8. **倒叙里的「昨日」**：要换算成追述现场的前一日，而不是当前叙述章节的前一日。
9. **正文混入后记**：末章里出现作者后记、版本说明时，其中的年份（如「一九八〇年五月」）不是故事内时间。
10. **同词异义**：「三年」可能指前史、闭关、年龄或跳跃，必须读上下文定归属。

## 每轮操作

1. 运行 `scripts/extract_anchors.py` 生成报告（写文件，不刷屏）。
2. 按章节顺序通读命中，逐条定 A／B／C 级；删除 C 级。
3. 把 A 级按时间先后排成一条链，作为 S3 时间轴的骨架。
4. 对资料里每一条带数字或引文的断言回查位置，错标回目的直接改。
5. 保留一份「错误清单」：原写法 / 核查结果 / 原文依据 / 已订正位置。它同时是交付质量记录，也是后续复核的入口。
