# 交付物格式与校验

## 三件套

| 交付物 | 形态 | 用途 |
|---|---|---|
| **时间线 × 剧情对照表** | 四列表，每章一行（章内跳跃拆多行） | 速查、逐回核对 |
| **剧情简写** | 按发生顺序的白话梗概，每章一段，段首两组标记 | 通读、写作时定位 |
| **评估笔记**（可选） | 错误清单 + 并行窗口表 + 留白点 | 决策记录、复核入口 |

三者用同一套章节编号与年份换算。若用户只要一张表，就只交表，但内部仍要完成 S0–S4 的核查，不能因为输出简单而跳过订正。

## 对照表

```
| 时间 | 回 | 回目 | 剧情 |
```

- 「时间」列：相对纪年 + 季节；原文明写的季节日期加「」；推演加「约」或 `≈`。
- 「回」列：纯数字；章内跳跃用 `40前 / 40中 / 40末`，保留数字便于校验。
- 「回目」列：原书章名，逐字核对，不用自拟标题。
- 「剧情」列：每章 2–4 条主干，含起因、经过、结果与关键转折；只写 1–2 条极易漏掉暗线。
- 文首写四句说明：依据文件与章节数、哪些是硬锚点哪些是推演、全书跨度、原著与改编／倒叙的提醒。

## 剧情简写

段首格式：

```
**〔绝对时间｜相对时点／地点〕第 N 回 · 回目**　【起点 → 终点 ≈ 距离｜在场角色档位】正文……
```

- `〔〕`：前半是「第 N 年 · 季节」，后半是原文日数、日期或相对位置，便于直接算「能不能赶到」。
- `【】`：前半是地点转移与距离，后半是**此刻**在场角色的档位；用 `→` 表示本章发生跃迁。
- 并列事件用「同时（<窗口>）」显式点明；章内多次跳跃拆成多段，每段都标 `第 N 回`。
- 结构按时间分节（前史 / 第 1 年春 / 第 2 年冬 / 末章跳跃），每节开头可加一句重排说明。

### 文首四段说明（不可省）

1. 依据文件、章节数、逐回核对的声明；
2. 标记符号约定与「硬锚点／推演」的区分方式；
3. **年份换算**：起点、主线终点、每次跳跃落在第几年、总跨度、最大留白；
4. **距离与实力规则**：单位、取整、日速、`≈` 含义、档位依据、免责说明。

紧跟其后的两张速查表：主要地点转移（起点→终点、距离、原文依据／耗时）与实力档位表＋跃迁曲线。缺了这些，读者会把推演当成原文。

## 评估笔记

```
### 错误清单
| 原写法 | 核查结果 | 原文依据 | 已订正位置 |

### 分身乏术窗口
| 窗口 | A 边 | B 边 | 为什么不能兼顾 | 原文依据 |

### 留白点
起止 / 期间原著写了什么 / 结束时已改变的设定
```

错误清单要保留，它记录了资料可信度的演变；订正时**两份交付物同时改**。

## 校验清单

1. 对照表数据行数 = 章节数 + 拆分行数；
2. 对照表每行列数一致，`回` 列可解析出数字；
3. 简写剧情段数 ≥ 章节数，段首都带 `〔〕`（启用地理实力时还要带 `【】`）；
4. 两份文档的章节号集合都覆盖 `1..N`，且彼此一致；
5. 所有 A 级锚点的引文能在原文中逐字检索到；
6. 文首跨度结论、时间轴、备注三处数字一致；
7. 每次章内跳跃都单独成段／成行；
8. 距离与档位规则、免责说明已写在文首；
9. 影视改编、版本差异、倒叙框架已在文首或脚注消歧；
10. 交付物中不含小说原文全文或大段复制（版权）。

## 脚本校验

```bash
python scripts/validate_deliverables.py \
  --table 剧情时间线.md --synopsis 剧情简写.md \
  --chapters 40 --expected-cols 4 --require-geo-power
```

输出每项的通过情况与具体缺失段落，退出码 0 表示全部通过；`--json` 可输出结构化结果供后续自动化使用。脚本只做结构校验，**不替**人工核对引文与事实，第 5–10 项需人工完成。
