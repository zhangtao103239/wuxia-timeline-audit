# 时间轴重建与可插入性评估

## 一、倒叙归位

章回小说极少全程顺叙。叙述顺序 ≠ 发生顺序，直接按章节排时间线必错。

### 识别信号

- 追述动词：「原来」「当日」「那日」「日前」「后来」「早在」「起初」「先是」「却说」；
- 转述框架：茶馆、花厅、公堂、宴席上某人「把前情说了一遍」「当众追述」，或「某人才得知」；
- 视角切换：第 1 章是甲视角顺叙，第 2–3 章忽然由乙向同门讲出甲不知道的事；
- 关键物首次出现的回目异常靠后（如「剑谱」二字到某章才出现），说明前面的相关叙述是追述或含糊指代。

### 处理

1. 把被追述的事件抽出来，单列「**前史**」或插回真实时刻，并在该处注明「原著于第 X 回倒叙讲出」。
2. 顺叙主线按真实时间重排，写明重排结果（例如：灭门 → 逃亡 → 救人 → 茶馆聚会 → 大会 → 授谱）。
3. 追述现场本身仍是一个事件（有人在场、有人听讲、有人因此起疑），不能因为内容是旧事就删掉这一段。
4. 在对照表里保留叙述顺序，在剧情简写里采用发生顺序；两份文档的章节集合必须一致，差异用文首说明消歧。

## 二、相对纪年与跨度自洽

### 纪年规则

- 默认用 **「第 N 年 · 季节」**，N 从故事起点算起，不套公元、不套作者生平。
- 作品给出明确历史纪年（年号、干支）时改为原纪年，农历日期保留原字样并另注换算。
- 季节由 A 级锚点定；同一事件链跨年分界时（如「前夜／正日」恰好在年关），标成「第 1 年冬末～第 2 年初春」，并在文首说明季节是粗推演、同链事件以原文相对日数为准。
- 文首必须写一段**年份换算说明**：起点、主线终点、每次跳跃落在第几年、全书总跨度、最大留白在哪一段。

### 三步自洽检查

1. **列出全部 A 级时间锚点**，按发生先后排成链，作为唯一骨架。
2. **核对三处数字**：文首跨度结论、逐段时间轴、避坑提示／备注。三者不一致即为硬伤。常见情形：推演轴已写到「第 3 年春末」，结论却仍写「不到两年」。
3. **扫描章内跳跃**：末章或任何一章里出现「三年后」「四个月后」「这三年半来」时，把该章拆成多段／多行，各自标时间。漏掉一次跳跃就会把全书跨度算短数年。

### 硬时钟陷阱

以下数字**不能**当作计时器，只能当情节信息：

- 医者／毒师判的死期（「百日之命」「多则半年，少则三月」）；
- 判罚或约定的期限（「面壁一年」「一月之内」「三年之内报仇」）——常被突发事件打断；
- 旁人回指旧事的年数（「十二年来」「早在一年之前」）——指向过去，不是当前跨度；
- 夸张语（「万里迢迢」「千里之外」）——文学修辞，不作距离换算。

反之，人物**因伤昏迷、被囚、面壁的实际时长**（「三月有余」「住了半年」「囚居数月」）是硬锚点，必须计入跨度。

## 三、并行线与「分身乏术」窗口

### 识别信号

| 类型 | 原文信号 | 后果 |
|---|---|---|
| 长期物理隔离 | 面壁、闭关、囚居、地牢、养伤、昏迷、软禁、被点穴 | 主角在一处无法移动，外界同时推进数月至半年 |
| 同日两地 | 「同时」「便在此时」「这十四日间」「另一方面」；A 处发现尸体而 B 处早已下手 | 一个视角只能跟一处 |
| 同场不同位置 | 大会、封禅台、混战，台上比剑／台下暗算 | 需要分视角或分兵 |
| 无目击者暗场 | 「后来才推证」「凶手当时无人看见」、事后由信件或转述补出 | 跟主线走必然不知道 |
| 原著自己分兵 | 「我和 X 先去东峰……Y 随着 Z 去救人」 | 作品本身已给出分头行动范式 |

### 三分类输出

| 分类 | 判据 | 输出内容 |
|---|---|---|
| **① 赶得上** | 同一路线顺次发生；原文给了行程日数与事件间隔，且余量充足；或全员集中一处的大会 | 列出可连续串场的章段与路程依据 |
| **② 必须二选一** | 上述任一隔离／同时信号成立 | 每个窗口一行：`窗口｜A 边｜B 边｜为什么不能兼顾｜原文依据` |
| **③ 暗场** | 原著无现场目击者，靠倒叙／书信／推证补出 | 事件清单 + 补出它的章节；这些点对同人最自由 |

### 「赶得上」的量化判断

用地理模块产出的距离除以日速，得到最少耗时；与原文给出的事件间隔比较：

```
最少天数 = ceil(两地距离 ÷ 日速上限)
若 最少天数 ≤ 间隔天数（并留出余量）→ 可赶到
否则 → 必须放弃一边，或改写行程方式
```

- 原文写「连日连夜」「每天只睡一两个时辰」「两匹马替换乘坐」时取快马上限；写「缓缓东行」取常规速度。
- 水路、换骑、渡江、关隘盘查都要单独计时，不能按直线距离一除了事。
- 判断结论写「按推演可赶到／按推演赶不上」，不要写成原文事实。

### 三种兼容写法（想让主角两边都沾又不崩原著）

1. **分兵**：照原著已有的分头行动范式，主角与同伴各走一边，事后汇合。
2. **信息差**：用书信、门人传话、事后追述把 B 边信息带到 A 边（原著茶馆倒叙就是范本），主角不必亲临。
3. **专攻暗场**：主角专走无目击者的暗场线，主线留给原主角；冲突最小、自由度最高。

## 四、留白点

跨度内的长空白（末章「三年后」之类）要单列，写明：起止、期间原著写了什么（可能只有一句回叙）、可自由展开的尺度。这是同人最有价值的区间，但也要注明哪些设定在空白结束时已改变（掌门易位、武功圆满、人物亡故），避免开篇就矛盾。
