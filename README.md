# wuxia-timeline-audit

把一部**有原文全文的武侠小说**拆成同人写作／改编能直接用的结构化资料：

1. **时间线 × 剧情对照表** —— 每回一行，逐回核对，速查用；
2. **剧情简写** —— 按事件真实发生顺序用白话重讲，每段带时间、地点转移距离、在场角色实力档位；
3. **可插入性评估** —— 哪些剧情主角赶得上、哪些同时发生只能二选一、哪些是原著无目击者的「暗场」。

方法本身不绑定任何一部作品。适用于各类章回体或分章的武侠、仙侠、历史演义小说（金庸、古龙、梁羽生、温瑞安、还珠楼主，以及网络长篇），也适用于有明确分集的剧本。前提是**手上有原文全文文件**；只有剧集印象或百科条目时无法核对。

## 解决什么问题

写同人或做改编时最常见的几个坑，这套流程专门处理：

- 已有的时间线文档与原著对不上（出处回目错、人物张冠李戴、把推演当原文）；
- 原著大量事后倒叙，按章节顺序读出来的「时间线」其实是错的；
- 结尾章藏了「三年后」「四个月后」这类跳跃，全书跨度被严重低估；
- 主角被关在山崖／地牢数月，外界同时推进，根本不可能两边都到场；
- 想写「主角恰好赶到某场戏」，却不知道两地相隔多远、按原文行程要几天；
- 想写打斗，却不清楚某角色在此刻究竟是什么水平、什么时候完成跃迁。

## 方法概览

| 阶段 | 做什么 | 关键约束 |
|---|---|---|
| S0 原文体检 | 编码、章节结构、字数、混入内容 | 建立「章节号 → 位置」索引 |
| S1 锚点提取 | 批量检索时间／地点／行程／状态／评价词 | 引文必须能逐字回溯 |
| S2 事实核对 | 逐条查出出处、人物、因果、遗漏 | 区分影视改编与版本差异 |
| S3 时间轴重建 | 倒叙归位、相对纪年、跨度自洽 | 硬锚点与推演分离 |
| S4 并行线评估 | 赶得上／二选一／暗场三分类 | 每类给原文依据 |
| S5 地理与实力 | 距离与日速、档位与跃迁曲线 | 虚构地名不硬编公里 |
| S6 交付校验 | 两份文档 + 可选评估笔记 | 章节覆盖、标签齐全、互证一致 |

三条铁律：**原文优先**、**硬锚点与推演分离**、**两份交付物互证**。

## 安装

**作为 WorkBuddy Skill**：把整个目录放到用户级 skills 目录，重启会话后即可按描述自动触发。

```
~/.workbuddy/skills/wuxia-timeline-audit/
```

也可放到单个项目的 `.workbuddy/skills/` 下，供项目成员共享。

**只当工具用**：不装 skill，直接跑 `scripts/` 里的两个 Python 脚本即可，无第三方依赖，Python 3.8+。

## 快速开始

```bash
# 1. 体检原文 + 抽取锚点（结果写入报告文件，避免刷屏）
python scripts/extract_anchors.py /path/to/novel.txt --output anchors.md

# 2. 章节格式特殊时，传入带命名组 num / title 的正则
python scripts/extract_anchors.py novel.txt \
  --chapter-pattern '第(?P<num>[一二三四五六七八九十百]+)回\s*(?P<title>\S+)' \
  --keywords my_keywords.txt --output anchors.md

# 3. 交付物校验
python scripts/validate_deliverables.py \
  --table 剧情时间线.md --synopsis 剧情简写.md --chapters 40 --require-geo-power
```

`--keywords` 接受一个每行一个词的文件；不传则使用内置通用词表（时间、节令、行程、里数、死亡、权力转移、实力评价等）。`--list-chapters` 只输出章节清单，用来先确认解析是否正确。

## 标注约定

```
**〔绝对时间｜相对时点／地点〕第 N 回 · 回目**　【起点 → 终点 ≈ 距离｜在场角色档位】正文……
```

- `〔〕`＝时间；`【】`＝地点距离与实力档位；
- 「」内为原文原字样（季节、日期、里数、评语）；
- `≈`＝推演换算；原文明写的数字不加 `≈`；
- 年份一律用「第 N 年」相对纪年，除非作品本身给出历史纪年。

## 案例

`references/worked-example.md` 记录了一次完整实测（《笑傲江湖》，40 回、约 99 万字符）：查出原文档把全书跨度写成「不到两年」而实际约 5 年半，纠正了十余处出处与事实错误，重建出 42 行对照表、45 段带标记的剧情简写、六个「必须二选一」的并行窗口，以及 T0–T4 实力档位表。案例只保留结论与必要短引文。
